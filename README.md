# userscripts

This is where I publish my userscripts.  To install any of them:

- Install [Tampermonkey for Chrome](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo?hl=en)
or [Tampermonkey for Firefox](https://addons.mozilla.org/en-US/firefox/addon/tampermonkey/).

- Select a script from this list, then click **Install this script**, then click **Install**:
  - [google-maps-saved-list-to-gpx.user.js](https://raw.githubusercontent.com/ocococococ/userscripts/main/google-maps-saved-list-to-gpx.user.js)
  - [arr-ext-to-button.user.js](https://raw.githubusercontent.com/ocococococ/userscripts/main/arr-ext-to-button.user.js) - adds an ext.to search button on Sonarr/Radarr/Lidarr pages
  - [ext-to-arr-push-button.user.js](https://raw.githubusercontent.com/ocococococ/userscripts/main/ext-to-arr-push-button.user.js) - adds a "Send to Sonarr/Radarr/Lidarr" button on ext.to search results
